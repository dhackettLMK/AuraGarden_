# AuraGarden

A gift for Laura: a life OS where every finished task earns aura from Oscar the Turtle and grows her garden.

This repo is the build pack. Claude Code builds the app from it.

## Start the build

Open this repo in Claude Code and paste:

```
Read CLAUDE.md and AURAGARDEN_BRIEF.md end to end before writing any code. They are the full spec for AuraGarden. Build it phase by phase as section 13 describes, verify and commit every phase, and keep PROGRESS.md up to date. At the end, prepare the deploy as section 14 describes. Never block on missing inputs: use tasteful placeholders and list them at handover.
```

If a session ends partway, start a new one with:

```
Read CLAUDE.md, AURAGARDEN_BRIEF.md and PROGRESS.md, then carry on from the next unfinished phase.
```
