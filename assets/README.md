# Logo assets

Use these files as they are. Never redraw, recolour or stretch them. Copy them into `public/brand/` at build time.

| File | Size | Use |
| --- | --- | --- |
| `logos/setu-logo.png` | 370×156, transparent | College Work project, in a white rounded tile, 48 px and larger |
| `logos/setu-mark.png` | 151×151, transparent | The SETU emblem alone, for College Work icons under 48 px |
| `logos/swapnserve-smiley.png` | 512×512, transparent | Swap 'N' Serve project icon at every size |
| `logos/swapnserve-cup-logo.png` | 1800×1204, transparent | Full Swap 'N' Serve Cup logo. Its lettering is white, so show it only on a dark tile (project header) |

Colours sampled from the logos:

- SETU slate: `#445463`
- Swap 'N' Serve smiley yellow: `#F6C828`

The SETU files are small. If an official SVG turns up later, swap it in at the same paths.
